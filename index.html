Colombo Stock Exchange API — Documentation

Base URL: https://www.cse.lk/api/

All endpoints below use POST requests with application/x-www-form-urlencoded data. A GET returns 405; a JSON body returns 400.

📡 Live WebSocket feed: wss://www.cse.lk/api/ws/websocket — see WEBSOCKET.md

chartData

Returns INDEX data, not stock data. The symbol parameter is not required and is silently ignored.

Parameters: chartId + period (both required, else HTTP 400)

chartId is a sectorId: 1 = ASPI, 40 = S&P SL20, 223 = Energy, or any sectorId from allSectors.

period: 1 intraday · 2 week · 3 month · 4 quarter · 5 year

curl -X POST https://www.cse.lk/api/chartData -d "chartId=40&period=1"

Parameters: stockId, period (1–5)

Live WebSocket Feed 📡

STOMP over WebSocket at wss://www.cse.lk/api/ws/websocket — no API key, no auth. Subscribe to /topic/<feed> for broadcasts, or publish to /app/request-<feed> and get an immediate snapshot on /user/topic/<feed>.

Feeds: aspi, snp, summary, status, top-gainers, top-looses, most-active-trades, today-sharePrice, daytrade.
